# WP-S S.6 — J1 Mode C clearance check (C9, reported) Implementation Plan

**Goal:** J1 (pipe nipple B1 ↔ solid B2, joint edge JE2, closed butt joint, coaxial with the positioner axis) in
Mode C: one robot pose at rest, the positioner turns 360° + closing overlap. Choose the pose by a ψ × 8 IK-branch
sweep at the J1 points facing the robot at θ = 0 (F4 / F5 / F9 scores, S.3 node cost, F7 tie-break), then step θ at
the B-03 angular step and check F4 validity, F5 weld clearance (5 mm, unpadded, lower bound by levels) and F9 contact
against the rotated part and holders at every θ. Result = clearance report per θ (TST-002 C9: reported, does not
gate). No Mode B, no Pivot step, no tuning of F-definitions or thresholds.

**Spec:** `PLAN.md` §3 WP-S S.6 and S.7 record fields; TST-002 Rev 0.3 DRAFT §5.1 F4, F5, F7, F8, F9, F10, §5.3 C9,
§9; DES-001 Rev 0.6 DRAFT §4.3 step 3 (Mode C: head checked against the rotating part and holders over the full turn
plus the overlap, with the contact check), step 6 / §5.4 (positioner steps Δθ ≤ 2·(c − margin) / r_max, B-03), §6.3
(robot at rest, ω = travel speed / radius + closing overlap); `docs/generated/spike/s4_open_items.md` (m6 clearance
links, F9 thread finding at J1); S.5 plan (seam input from the exact D20 joint edge).

**Decisions taken in by this plan (Truong / lead, 2026-11-04):** H-BOX head model; clearance links = TST-002 F5 set
(head_body, head_mount, conduit), configurable, recorded (m6 open); J1 = JE2; engineer choices (contact-point
sampling, ψ cases, closing overlap, angular-step margin, alternates) live in the data file
`docs/generated/spike/s6_mode_c_input.yaml`, never in source. TST-002 §11 is not filled here (S.7, lead).

**Readings (Assumptions, recorded in the result):**

- **B-03 angular step:** Δθ_max = 2·(c − margin) / r_max with c = weld clearance 5 mm (the level verified at every
  checked θ), margin = clearance guaranteed between two checked angles. TST-002 / DES-001 give no margin value;
  the data file sets margin = 3 mm (= F4 `padding_mm`, Assumption). r_max = largest distance from the positioner axis
  of any vertex of the rotating set (cell objects on `positioner_flange` + job objects on it), computed from the
  scene meshes and recorded. Between two checked angles the guaranteed clearance is min(lb_k, lb_k+1) − r_max·Δθ / 2.
- **Rotation direction:** the sign of θ is chosen so that the contact point advances along the seam travel
  direction (+X of the seam frame, s increasing). Span = 360° + overlap_mm / r_seam (overlap = D04 `arc_overlap_mm`
  of the Mode C seam, arcs = 1 → closing overlap).
- **F9 per θ:** the TCP (contact point) is fixed in `world` while the part turns. Per θ the contact check runs on
  part_T_tcp(θ) = (world_T_flange(θ) · flange_T_part)⁻¹ · world_T_tcp — the real relative pose, so eccentricity and the
  helical thread are seen as they are. world_T_flange(θ) = world_T_flange(0) · Rx(θ) (flange X = axis, frames.yaml),
  verified against `/compute_fk` at sample angles (deviation recorded). F9 is also profiled on a finer θ grid (data
  file) because it is cheap and the thread varies along the turn.
- **F8:** coaxiality of the J1 circle with the positioner axis is measured and recorded (0.05 mm / 0.1°); a fail is
  reported, the check still runs (it would mean Mode B / robot-only, B-03).
