## Rules kept

- The browser never reaches ROS. `awm_api` starts `ros2 run awm_bringup replay_program --program <file>` as a run
  (B-11: subprocess, no rclpy). One slot per cell (409 busy), cancel = SIGTERM to the process group (runner).
- The replay CLI is the only thing that talks to the controller and it refuses non-mock hardware (exit 2). The API
  adds nothing that could bypass it: no options other than `--program`, no config override, no segment selection.
- A replay is a request against the sim_mock the user launched. Nothing starts sim_mock from the API.
- A stale program (awm_core.staleness, the same rule as the CLIs) is refused before any process starts (409
  `program-stale` with the problems). The newest program is replayed; an older one only when named explicitly — and
  it is still checked.
- Units: the replay summary is deg / s already (CLI); the API passes it through unchanged.
