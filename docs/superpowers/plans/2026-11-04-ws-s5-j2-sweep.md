## Task 1 — seam input from the exact joint edge (pure)

**Files:** `src/awm_path/awm_path/core/seam_input.py`, test `test/test_core_seam_input.py`.

- `read_glb_edge_polyline(glb, edge_id)` — numpy GLB reader (D20 edge node, mm); refuses a missing / non-line node.
- `fit_circle(points)` — centre, axis, radius, max residual. Used only when the D20 `curve_type` of the joint edge is
  `circle`; the polyline vertices are points of the B-Rep edge, so the fit is the exact curve within float32 / fit
  residual (checked ≤ `tol_mm`, else refused). Other curve types → refused ("needs D04 v2 geometry, T2.2").
- `circle_joint_geometry(...)` — D04 v2 `geometry.points` (s, p, t, n1, n2) at a given spacing: start = edge start
  (preview frame 0), travel direction = edge parameter direction (preview frame 0 X), n1 = n2 = radial (DES-001 §4.3:
  tube butt joint), **checked** against every D20 preview frame (joint-aware B-Rep bisector): point ≤ `tol_mm`, Z and
  X ≤ `tol_deg`; any mismatch refuses the input (no fallback).
- `frames_at(points, s_values, closed)` — seam frames (X = t, Z = bisector(n1, n2), Y = Z × X) by interpolation
  along s (wrap on closed seams).
- `arc_ranges(length, arcs, overlap, closed)` — CP-53: equal lengths from the seam start, each arc extended by the
  overlap (the last over the start on a closed seam); `arcs` = 1 on a closed seam → error "net 360° joint turn" is
  the caller's report, not decided here.
- Tests: synthetic circle polyline → fit exact; frames orthonormal, Z radial; mismatched preview frame → refused;
  arc ranges for 2 / 3 arcs with overlap, closed wrap; GLB round trip with a hand-built file.
- Commit `awm_path: S.5 seam input from the exact D20 joint edge, arc split (CP-53)`.

## Task 2 — pitch refinement (CP-53 / F1) and result metrics (pure)

**Files:** `src/awm_path/awm_path/core/s5.py` (or extend `sweep.py`), test `test/test_core_s5.py`.

- `max_label_steps(layers)` — per step, max |Δq| over (ψ, label) pairs kinematically valid at both points.
- `refine_pitch(n_points_fn, ...)` — start at the F1 ceiling, double the points until every step ≤ Δq_max or the
  pitch floor (`pitch_min_mm`, Assumption 0.05 mm) is reached; returns pitch, points, max step, iterations.
- `classify_points(layers, columns, contact)` — per point: valid node count, reason class counts (IK = no_ik_*,
  joint_limit, singular_*; F4; clearance; contact), colliding pairs (F4 contacts and clearance blockers with counts).
- `path_metrics(path, params)` — C3 values measured on the returned path: labels, max |Δq|, wrist-3 travel, |q6|max.
- `coverage(...)` — C2 % points with ≥ 1 valid node; longest continuous DP window (diagnostic, C8 note);
  C8 (2 arcs) = covered seam length of accepted arcs / seam length.
- Tests on synthetic layers / scores.
- Commit `awm_path: S.5 pitch refinement, failing-point classes and C2 / C3 / C8 metrics`.
