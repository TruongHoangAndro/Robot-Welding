# G1.2 — joint seams (D04 v2) and the seam in the positioner frame (`seam_axis.json`) — Task Plan

> Agent: `seam-process`, branch `g1-2-seam-axis`. Master plan: `2026-11-05-goal1-coverage-ui-to-sim.md` (G1.2).
> Spec: PLAN.md T2.2; CP-52 (joints between solids), CP-53 (arcs), CP-58 decision 2 (seam in the positioner frame),
> CP-59 (`positioner_mode: sync | C | B`); DES-001 Rev 0.5 §4.3 step 1, §5.2, §5.3; contracts T0.5 v2, D20 v2.0.

## Design

1. **Pick → joint.** A picked edge id (`E<n>` of either solid) is looked up in D20 `topology.json`; its
   `joint_edge_id` names the joint. All picks of one seam must name the same joint; an edge without a joint is
   refused (Goal 1 welds joints between solids only). Pure Python (`awm_seam.joint_seams`).
2. **Sampling (B-Rep, conda process).** New `awm_geometry.joint_seam` + CLI `sample-joints --job --request --out`:
   loads `cache/model.brep` (hash checked against `part.json`), maps the joint edge / solid ids of `topology.json`
   onto it (length check), samples the joint edge of `solid_a` at a pitch ≤ 1 mm (equal spacing, exact curve
   points), weld direction = curve direction of `edge_a`, flipped by `reversed`; start = `start_offset_mm` along
   the curve direction from its first vertex (closed seams), or a start point projected on the edge. n1 / n2 =
   exterior-face normals of solid a / b (`awm_geometry.joints`). Output in mm through `awm_core.units`.
3. **D04 v2 (MINOR 2.1).** `seams.schema.json` gains `positioner_mode` (`sync` default | `C` | `B`, CP-59),
   `positioner_angles_deg` (one per arc, only for `B`), `start_offset_mm`. Example updated.
4. **`seam_axis.json` (new schema `v2/seam_axis`).** Per seam point: position and seam frame (quaternion) in the
   `positioner_flange` frame at θ = 0, `r_mm`, `axial_mm`, `phi_deg` (unwrapped along the seam; φ = atan2(z, y)
   about the axis +X). Transform = `placement.flange_T_part` (`awm_core.frames`); `frames.yaml`
   `world_T_positioner_axis` checked for the axis convention (x = axis). Header inputs: SHA-256 of `seams.json`,
   `placement.json`, `../../cell/model/frames.yaml`; reader refuses stale inputs. Per seam: arcs (s ranges),
   coaxial test (r spread, axis angle; tolerances are parameters with Assumption defaults).
5. **CLI** `ros2 run awm_seam joint_seam build|axis|show --job <dir> ...` (= `python3 -m awm_seam.joint_cli`).

## TDD steps

1. Schema tests (awm_core `test_jsonio` already validates every v2 example) → add `seam_axis` schema + example,
   seams 2.1 fields; test: B without angles refused by the schema.
2. `awm_seam/test/test_joint_seams.py` (pure Python, synthetic topology): pick either edge → same joint; unknown /
   non-joint / mixed picks refused; attribute checks (arcs, overlap, mode B angles count).
3. `awm_seam/test/test_seam_axis.py` (pure Python, synthetic samples): part → axis → part round trip ≤ 1e-6 mm;
   coaxial ring r spread ≤ 0.01 mm, off-axis ring not coaxial; stale `seams.json` / `placement.json` /
   `frames.yaml` refused; reversed direction reverses the φ order; schema validation of both files.
4. `awm_geometry/test/test_joint_seam_occ.py` (conda): `tube_tube` synthetic part → sample both joints; pitch ≤
   1 mm, radial Z, reversed / start offset.
5. `awm_seam/test/test_joint_cli.py`: end to end through `occ_bridge` (needs `AWM_OCC_PYTHON`) on `tube_tube`;
   spike-data test on the golden part through `AWM_SPIKE_REPO` (skips with reason if unset): J1 r = 13.33 ± 0.01 mm
   coaxial, J2 not coaxial.
