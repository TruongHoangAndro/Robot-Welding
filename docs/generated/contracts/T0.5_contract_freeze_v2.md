## Rules fixed by this freeze

1. **Units.** mm, degrees, seconds everywhere (`*_mm`, `*_deg`, `*_s`). Joint values in D07 / D09 are **unwrapped
   degrees**; `awm_motion` converts to rad for the controllers through `awm_core.units` only.
2. **Rotations** are unit quaternions `quat_xyzw`; readers normalise and refuse |q| outside 1 ± 1e-6 (answers S.2
   review R3: no rotation matrices with rounded entries in files).
3. **Shape identity (N1).** `part.json.source` = STEP file + SHA-256 + `component` (null = whole file) + `up_axis`. Every
   id-based file of the job (edges.json, D20, seams.json) is built from this shape; producers take the component from
   `part.json`, never from a separate argument.
4. **Seam geometry is self-contained** in D04 (`geometry.points`: s, p, t, n1, n2) with the face ids of n1 / n2 (contact
   check F9) and the solid pair of the joint.
4a. **Arcs (CP-53).** D04 `arcs` (≥ 1, Engineer-entered in S2, never chosen by software) and `arc_overlap_mm`; D07 has
   one entry per arc (`arc.index` / `arc.of`); a seam is weldable only when every arc is accepted.
5. **No partial path.** D07 `seams` holds only seams accepted at 100 %; `rejected` carries the reason, the C8 coverage
   fraction (reported only) and the failing points with reason counts and colliding link / object.
6. **Context record** (B-10) in D07, D09, D10; fields not available in a stage are `null`, never omitted; new fields
   only by MINOR changes.
7. **D09** has one segment per controller (`robot` / `positioner`) with `hold_deg` for the other axes and points with
   positions, velocities and accelerations exactly as commanded. Weld events reference the segment after which both
   axes are at rest (DES-001 §6.2).
8. **Release** = manifest of every file in `programs/<rev>/bundle/` with SHA-256, `locked: true`; the job keeps
   `active_simulation.json` / `active_production.json`. Scope enum is `simulation` / `production`; `trial` waits for E-02.
9. **Placement** `verified: false` until REF_* markers and A52 / A53 exist; only simulation scope accepts it (B-12).
